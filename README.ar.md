**العربية أولًا. لغات أخرى لاحقًا. وبالمجتمع نطوّر التجربة.**

> **مشروع تجريبي مستقل، وليس إضافة رسمية من DeepSeek.** الإصدار الحالي مقيّد بـ **DSH `0.2.2-rc.2`**. نجحت اختبارات المصدر والخدمات، لكن انعكاس واجهة Desktop والسحب والتوافق بين الأنظمة **لم يحصل على اعتماد مرئي شامل**. راجع [سجل التحقق](<docs/verification.md>) قبل استعماله في مساحة عمل مهمة.

## لماذا هذا الاسم؟

**Polyglot** يعني متعدد اللغات. بدأنا بالعربية؛ الاسم يعبر عن اتجاه المشروع، وليس عن أن كل اللغات مدعومة اليوم. نريد واجهة تتحدث لغة مستخدمها دون تغيير محتوى محادثاته أو العبث بالأكواد أو فرض تفضيل لغة عليه.

## ما الموجود حاليًا؟

- **57 نطاق ترجمة و2,886 مفتاحًا** عبر خدمة اللغة الأصلية، دون ترجمة شبكية أو استبدال نصوص DOM.
- اختيار العربية في طبقة الحزمة الأقل أولوية؛ تفضيل المستخدم المحفوظ يتقدم عليه.
- نصوص التنقل والبطاقات يمينًا وأيقوناتها الأساسية يسارًا، مع مساحة مستقلة لأزرار التحكم.
- حماية هندسة مفاتيح التفعيل دون تغيير شكلها أو ألوانها أو وظائفها.
- نقل مشروط لشريط الدردشات يمينًا ولوحة الملفات والمتصفح والطرفية يسارًا **عند تحميل المحول الأصلي المتحقق منه فعليًا**.
- زر الإرسال في الطرف الأيسر؛ هندسة التبويبات وdocking ومراسي القوائم تظل LTR عند الحاجة.
- الأكواد والطرفية والمحررات وحقول URL وكلمات المرور ومفاتيح API تبقى معزولة تقنيًا.
- لغات إضافية: **هدف مستقبلي** نرحب بالمساهمة فيه.

يبقى معرّف الحزمة **`@local/dsh-arabic-ui`** للحفاظ على توافق التثبيت السابق. اسم المستودع والمشروع المجتمعي هو **DSH Polyglot**. لا توجد حزمة npm منشورة بهذا الاسم حاليًا.

## التثبيت السريع

### 1. تنزيل المستودع

```bash
gh repo clone Mstrq4/dsh-polyglot
cd dsh-polyglot
```

استعمل إصدارًا منشورًا ومراجعًا بدل متابعة فرع التطوير في بيئة مهمة. البداية هي [v1.0.3](https://github.com/Mstrq4/dsh-polyglot/releases/tag/v1.0.3)، بإشارة **prerelease**:

```bash
git checkout --detach v1.0.3
```

[client.js](<client.js>) المولد موجود في المستودع: لا يلزم تثبيت تبعيات أو تنفيذ build لمجرد تثبيت النسخة المنشورة. **احتفظ بالمجلد**؛ تثبيت المجلد المحلي يربط الإضافة بهذا المجلد.

### 2. تثبيت الحزمة في DSH

1. تأكد أن إصدار DSH هو **`0.2.2-rc.2`** وأنه يستخدم الواجهة الرسومية وخدمة اللغة الأصلية.
2. افتح **الإضافات ← إضافة جديدة**.
3. أدخل **المسار المطلق لمجلد المستودع** الذي يحتوي [package.json](<package.json>)، وليس المجلد الأب أو ملف README.
4. اتبع نتيجة مدير الإضافات؛ ظهور التحديد المحفوظ لا يثبت نجاح التشغيل الحي. أعد التشغيل إن طُلب ذلك.
5. من **الإعدادات ← عام ← اللغة** اختر **العربية** إذا ظل اختيارك السابق مفعّلًا.
6. حدّث نافذة التطبيق لإعادة تحميل الإطار الأصلي، ثم افحص القوائم والمفاتيح والسحب، لا مجرد اسم الإضافة في القائمة.

للتثبيت بواسطة وكيل، أعطه [AGENTS.md](<AGENTS.md>) واطلب استخدام أداة `plugin_manager` بدل تعديل إعدادات الملف الشخصي يدويًا. راجع [الدليل التفصيلي](<docs/installation.md>) للتشخيص والتحديث والإزالة.

## الحدود المهمة

- الإضافة لا تترجم المحادثات والملفات والمخرجات والنصوص الخارجية أو بيانات الإضافات التي لا توفر العربية. شريط نظام التشغيل يظل أصليًا/إنجليزيًا عمدًا.
- لا نقلب `dir` للمستند كله؛ مراسي القوائم والبوابات تحافظ على إحداثياتها الأصلية.
- ناقل Desktop من نوع `dsh-app:` يحتاج تحققًا في النافذة الحقيقية؛ عند غياب مؤشرات المحول يبقى التخطيط المحافظ بدل قلب CSS غير الآمن.
- اختبارات CSS عقود مصدرية، **وليست لقطات شاشة أو اختبار سحب فعلي**. لا ندعي دعم RTL كاملًا لكل نسخة وكل نظام.

## ماذا يحدث بعد تحديث DeepSeek Harness؟

ملفات المستودع المنفصل لا تُحذف عادةً بسبب تحديث التطبيق. لكن بقاء الملفات **لا يعني استمرار التوافق**.

قد تتغير الخدمات أو Slots أو DOM أو ملفات JavaScript أو حسابات الإحداثيات. الحزمة تتعمد تثبيت `engines.dsh` والتحقق من بصمات المحولات؛ قد يُمنع التشغيل أو يتوقف انعكاس الأشرطة حتى نراجع البناء الجديد.

**لا تحذف الحماية لتجاوز المشكلة، ولا تمنح استثناء إصدار تلقائيًا.** الاستثناءات قد تسبب تعطلًا أو فقدان بيانات. عطّل الحزمة، وحدّث/أعد تشغيل النافذة، ثم أرسل معلومات الإصدار والبناء دون بيانات حساسة. راجع [المخاطر وخطة الرجوع](<docs/compatibility.md>).

## التطوير والوثائق

باستخدام **Node.js 24+**:

```bash
node scripts/build.mjs
npm run test:portable
```

CI المحمول يفحص البناء وعقود المصدر وروابط الوثائق والخصوصية؛ لا يمثل اختبار الواجهة الأصلية. المجموعة الكاملة تحتاج تثبيت DSH المتوافق وElectron القادر على قراءة ASAR عند وجوده. التفاصيل في [سجل التحقق](<docs/verification.md>).

عدّل [runtime.js](<src/runtime.js>) أو [القاموس](<dictionaries/ar.json>) ثم أعد البناء؛ لا تعدّل الملف المولد يدويًا.
