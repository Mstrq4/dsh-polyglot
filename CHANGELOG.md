# Changelog

Release status and compatibility are more important than a version number. See [compatibility](<docs/compatibility.md>) and [verification](<docs/verification.md>).

## 1.0.3 — initial public prerelease

Project published as **DSH Polyglot**; legacy bundle id `@local/dsh-arabic-ui` retained. Targets DSH **0.2.2-rc.2** only. Native adapter revision stays **1.0.2**.

### Included

- Arabic native locale registration: 57 namespaces / 2,886 keys and preference-safe bundle-layer selection.
- Scoped bidi/technical-content isolation and conservative native portal geometry.
- Fingerprint-guarded native frame/row adapters on plugin-owned HTTP aliases; no installation-file edits.
- Left-edge send action, coordinated experimental sidebar/toggle/tab rules and RTL-aware title-scroll adaptation.
- Universal semantic switch coordinate isolation and text-right/artwork-left plugin card/row rules with native controls preserved.
- Literal native-source replacement and narrow source-map metadata handling.
- English/Arabic onboarding, installation/architecture/compatibility/verification, agent rules and community contribution/security templates.
- Portable publication/build CI, provenance-path removal and public artifact hygiene.

### Evidence and limits

The pre-publication native/source baseline passed **62 tests**. Source/HTTP/Cordis boundary coverage is not rendered browser proof; Desktop carrier activation, visual positions, resizing and cross-platform checks remain unverified. This release is deliberately **experimental**, not a production RTL certification.

### Previous development iterations

Internal 1.0.0–1.0.2 development explored Arabic registration, conservative component-direction repair and guarded native mirroring. Those iterations were not published here as reviewed releases. Do not assume unpublished development tags or backup folders exist in this standalone repository.
